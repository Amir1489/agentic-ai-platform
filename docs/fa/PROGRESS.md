## تغییرات جدید — ۱ نوامبر ۲۰۲۶

- صف Task در پایگاه داده به‌عنوان نقطه پایدار انتظار استفاده می‌شود.
- API ایجاد Task اکنون HTTP 202 و وضعیت اولیه `queued` برمی‌گرداند.
- Worker پس‌زمینه Task را با UPDATE شرطی claim می‌کند؛ این روش از claim هم‌زمان یک Task توسط چند نمونه جلوگیری می‌کند.
- مسیر جزئیات Task برای polling اضافه شد و داشبورد وضعیت را تا پایان پیگیری می‌کند.
- آزمون‌های موفقیت و شکست ارائه‌دهنده برای چرخه صف/Worker بازنویسی شدند؛ نتیجه CI پس از اجرای گردش‌کار باید در همین بخش ثبت شود.
- محدودیت مهم: بازیابی Taskهای باقی‌مانده در وضعیت `running` پس از توقف ناگهانی فرایند هنوز وجود ندارد.

## تاریخچه انتشار

### ۳۱ اکتبر ۲۰۲۶ — بررسی قابلیت‌های AI در محیط عملیاتی
- بررسی امن مسیر `/api/capabilities` اضافه شد.
- رابط، سلامت بک‌اند و آمادگی پایگاه داده موفق بودند.
- محیط عملیاتی `chat: false` و `agent_tasks: false` گزارش کرد؛ در زمان بررسی، `AI_API_KEY` خصوصی در Render تنظیم نشده بود.

### ۳۱ اکتبر ۲۰۲۶ — بررسی زنده محیط عملیاتی
- گردش‌کار بررسی عملیاتی اجرا شد.
- رابط منتشرشده پوسته اصلی برنامه را برگرداند.
- مسیر سلامت Render موفق بود.
- مسیر آمادگی Render اتصال پایگاه داده را تأیید کرد.
- این بررسی اتصال سرویس و پایگاه داده را در زمان اجرا تأیید می‌کند، نه اعتبار کلید AI یا اجرای واقعی مدل را.

### ۳۱ اکتبر ۲۰۲۶ — تاریخچه پایدار کارها در داشبورد
- کارت‌های عامل پس از بارگذاری مجدد، اجراهای اخیر ذخیره‌شده را دریافت و نمایش می‌دهند.
- نتیجه کار جدید پس از اجرای موفق به تاریخچه محلی UI اضافه می‌شود.
- سبک واکنش‌گرا برای ورودی/خروجی کار و رکوردهای تاریخچه اضافه شد.
- ساخت فرانت‌اند و انتشار Pages در اجرای 41236934388 موفق بود.

### ۳۱ اکتبر ۲۰۲۶ — خط پایه مهاجرت پایگاه داده
- پیکربندی Alembic، محیط، خط پایه اولیه تکرارپذیر و قالب revision اضافه شد.
- Render پیش از Uvicorn دستور مهاجرت را اجرا می‌کند.
- CI خط پایه را دو بار روی SQLite تازه اجرا و سپس مجموعه API را آزمود؛ اجرای 41236687579 موفق بود.
- نصب موجود بدون حذف جدول‌ها پذیرفته می‌شود. تغییرات آینده به revision صریح و پشتیبان‌گیری نیاز دارند.

### ۳۱ اکتبر ۲۰۲۶ — نمای تنظیمات و سخت‌سازی اعتبارسنجی اجرا
- مسیر امن `/api/capabilities` اضافه شد.
- نمای تنظیمات داشبورد برای ایمیل حساب، نکات امنیتی و وضعیت ارائه‌دهنده اضافه شد.
- اجرای عامل از مدل انتخاب‌شده خود عامل استفاده می‌کند.
- اعتبارسنجی شناسه مدل اصلاح و آزمون بازگشت اضافه شد.
- آزمون بک‌اند و انتشار فرانت‌اند در اجراهای 41236572082 و 41236476001 موفق بودند.

### ۳۱ اکتبر ۲۰۲۶ — تأیید CI محیط اجرای عامل
- آزمون موفقیت/شکست کار، ذخیره‌سازی و رویدادهای ممیزی موفق بود.
- ساخت TypeScript/Vite و انتشار Pages موفق بود.
- اجرای زنده ارائه‌دهنده به دلیل در دسترس نبودن اعتبارنامه خصوصی در CI تأیید نشده است.

### ۳۱ اکتبر ۲۰۲۶ — نخستین مسیر اجرای محدود عامل
- رکورد پایدار کار و رویدادهای append-only برای started/succeeded/failed اضافه شد.
- مسیر `POST /api/agents/{id}/tasks` برای اجرای تک‌مرحله‌ای مدل اضافه شد.
- فقط عامل فعال و متعلق به کاربر قابل اجراست.
- تاریخچه کار و رویدادهای هر کار اضافه شد.
- ورودی تا ۸٬۰۰۰ و خروجی تا ۱۲٬۰۰۰ نویسه محدود شد.
- ابزار، shell، worker پس‌زمینه، تلاش مجدد، لغو، بودجه هزینه و برنامه‌ریزی چندمرحله‌ای وجود ندارد.

### ۳۱ اکتبر ۲۰۲۶ — آمادگی پایگاه داده و پایش
- مسیر `/api/ready` برای اجرای `SELECT 1` اضافه شد.
- آزمون آمادگی به مجموعه بک‌اند اضافه شد.
- smoke دوره‌ای رابط، سلامت بک‌اند و آمادگی پایگاه داده را هر شش ساعت بررسی می‌کند.

### ۳۱ اکتبر ۲۰۲۶ — پایه مدیریت عامل

- وضعیت‌های draft/active/paused و داشبورد مدیریت عامل اضافه شدند.
- آزمون جداسازی کاربران و تغییر چرخه عمر اضافه شد.
- فعال‌سازی عامل در آن مرحله فقط وضعیت پیکربندی بود.

### ۳۱ اکتبر ۲۰۲۶ — پایداری چت و ذخیره اتمی
- کنترل هم‌زمانی ایجاد/ارسال/حذف گفت‌وگو بهبود یافت.
- پاسخ ارائه‌دهنده پیش از ذخیره پیام‌ها تولید می‌شود.
- پیام کاربر و دستیار پس از موفقیت در یک تراکنش ثبت می‌شوند.
- آزمون مالکیت، نبود ارائه‌دهنده، شکست اتمی و ذخیره موفق اضافه شدند.

## قواعد ثبت پیشرفت
۱. هر تغییر معنادار باید این فایل و سند فنی مرتبط را در همان مجموعه تغییرات به‌روزرسانی کند.  
۲. درصدها بر اساس معیارهای پذیرش نقشه راه تخمین زده شوند.  
۳. SHA کامیت، لینک CI، نتیجه آزمون، وضعیت انتشار، محدودیت‌ها و یادداشت بازگشت ثبت شوند.  
۴. قابلیت صرفاً بر اساس ظاهر UI کامل تلقی نشود.  
۵. اطلاعات محرمانه و داده شخصی در log یا Git ثبت نشوند.

## موانع و وابستگی‌ها
- پیکربندی ارائه‌دهنده AI در Render تأیید نشده است؛ کلید API نباید در چت ارسال یا در مخزن ثبت شود.
- تنظیمات خصوصی Render و Supabase از طریق اتصال فعلی GitHub در دسترس نیستند.
- آزمون کامل مرورگر به محیط خودکارسازی و حساب آزمایشی نیاز دارد.
- استفاده از API ممکن است هزینه جداگانه داشته باشد؛ ChatGPT Free اعتبار API فراهم نمی‌کند.
