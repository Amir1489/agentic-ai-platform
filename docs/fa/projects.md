# API پروژه‌ها و گفت‌وگوها

API پروژه‌ها با بک‌اند FastAPI منتشر شده است. تمام مسیرها به هدر `Authorization: Bearer <token>` معتبر نیاز دارند.

## پروژه‌ها
- `GET /api/projects` فقط پروژه‌های کاربر جاری را فهرست می‌کند.
- `POST /api/projects` با بدنه JSON مانند `{ "name": "My project" }` پروژه ایجاد می‌کند.
- `DELETE /api/projects/{id}` فقط پروژه متعلق به کاربر جاری را حذف می‌کند. پروژه متعلق به کاربر دیگر پاسخ 404 می‌دهد.

داشبورد پس از ورود، در صورت پیکربندی `VITE_API_URL` از API استفاده می‌کند. بدون نشست احراز هویت‌شده و نشانی بک‌اند، پیش‌نمایش محلی مرورگر به کار می‌رود.

## بررسی عملکرد پروژه‌ها
۱. ثبت‌نام کنید یا وارد شوید.  
۲. پروژه بسازید و صفحه را تازه‌سازی کنید.  
۳. باقی‌ماندن پروژه را بررسی کنید.  
۴. با حساب دوم وارد شوید و مطمئن شوید پروژه‌های حساب اول قابل مشاهده یا حذف نیستند.

گذرواژه پایگاه داده، کلید API یا توکن Bearer را در متغیرهای GitHub Actions با پیشوند `VITE_` قرار ندهید؛ این مقادیر به داده عمومی بسته فرانت‌اند تبدیل می‌شوند. فقط نشانی عمومی بک‌اند باید در آن متغیر باشد.

## محدودیت‌های پروژه
جریان فهرست‌کردن، ایجاد و حذف پروژه پیاده‌سازی شده است. وضعیت عامل‌ها و گردش‌کار در داشبورد هنوز کامل نیستند. مهاجرت پایگاه داده و محافظت عملیاتی در برابر سوءاستفاده نیز نیازمند تکمیل‌اند.

## API گفت‌وگوها
تمام مسیرها همان احراز هویت Bearer پروژه‌ها را نیاز دارند.

- `GET /api/conversations` گفت‌وگوهای کاربر واردشده را فهرست می‌کند.
- `POST /api/conversations` گفت‌وگویی با عنوان اختیاری ایجاد می‌کند.
- `GET /api/conversations/{id}/messages` تاریخچه پیام‌ها را برمی‌گرداند.
- `POST /api/conversations/{id}/messages` پیام کاربر را به مدل پیکربندی‌شده می‌فرستد و پیام کاربر و دستیار را ذخیره می‌کند؛ طول هر پیام حداکثر ۱۲٬۰۰۰ نویسه است.
- `DELETE /api/conversations/{id}` گفت‌وگو و پیام‌های آن را حذف می‌کند.

مالکیت گفت‌وگو در هر عملیات بررسی می‌شود. بک‌اند از Chat Completions سازگار با OpenAI پشتیبانی می‌کند. مقدار `AI_API_KEY` را به‌صورت محرمانه در متغیر محیطی Render تنظیم کنید؛ `AI_BASE_URL` و `AI_MODEL` اختیاری هستند. مقدارهای پیش‌فرض، نشانی API شرکت OpenAI و مدل `gpt-4o-mini` هستند.

اطلاعات محرمانه ارائه‌دهنده را در متغیر فرانت‌اند قرار ندهید و در Git ثبت نکنید. استفاده از API ممکن است هزینه جداگانه داشته باشد؛ اشتراک رایگان ChatGPT اعتبار API فراهم نمی‌کند. بدون کلید، مسیر پیش از ذخیره پیام ارسال‌شده HTTP 503 برمی‌گرداند.
