# مستندات فارسی پروژه

این پوشه نقطه شروع مستندات فارسی سکوی هوش مصنوعی عامل‌محور است.

## فایل‌های Word

نسخه Word مستندات در بسته‌ای با نام `Agentic_AI_Platform_Word_Documentation_FA.zip` ارائه شده است. این بسته شامل هفت سند است:

1. معماری سامانه
2. وضعیت پیشرفت
3. نقشه راه
4. مستند API عامل‌ها
5. احراز هویت
6. راهنمای استقرار
7. پروژه‌ها و گفت‌وگوها

## اصل نگهداری مستندات

- زبان توضیحات و راهنماها فارسی باشد.
- نام مسیرهای API، متغیرهای محیطی، کلاس‌ها، توابع، کتابخانه‌ها و فرمان‌ها به شکل فنی اصلی حفظ شود.
- هر تغییر مهم در محصول باید در سند Word مرتبط و در صورت لزوم در مستندات این مخزن منعکس شود.
- وضعیت قابلیت‌ها باید از وضعیت واقعی محیط عملیاتی تفکیک شود.
- موارد آزمایش‌نشده یا پیاده‌سازی‌نشده نباید به‌عنوان قابلیت تکمیل‌شده معرفی شوند.
- هیچ رمز، توکن، کلید API یا اطلاعات اتصال محرمانه‌ای در مستندات ثبت نشود.

## نکته درباره وضعیت انتشار

در زمان تهیه این فهرست، بسته Word فارسی در محیط گفتگو تولید شده است؛ فایل‌های باینری Word هنوز در این مخزن Git قرار نگرفته‌اند. این صفحه به‌عنوان راهنمای ساختار مستندات فارسی نگهداری می‌شود.
