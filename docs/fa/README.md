## قواعد نگهداری

- زبان توضیحات، راهنماها و گزارش‌ها فارسی باشد.
- نام مسیرهای API، متغیرهای محیطی، کلاس‌ها، توابع، کتابخانه‌ها و فرمان‌ها به شکل فنی اصلی حفظ شود.
- هر تغییر معنادار محصول باید در همان مجموعه تغییرات، در سند مرتبط ثبت شود.
- وضعیت قابلیت‌های پیاده‌سازی‌شده، آزموده‌شده و فعال در محیط عملیاتی از هم تفکیک شود.
- موارد آزمایش‌نشده یا پیاده‌سازی‌نشده نباید کامل معرفی شوند.
- هیچ رمز، توکن، کلید API، نشانی اتصال یا داده شخصی محرمانه‌ای در مستندات ثبت نشود.
- مستندات در قالب متن Markdown باقی می‌مانند تا نسخه‌بندی، بازبینی و مقایسه تغییرات در Git ساده باشد.
