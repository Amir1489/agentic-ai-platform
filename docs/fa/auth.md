# احراز هویت

FastAPI مسیرهای ثبت‌نام، ورود، اعتبارسنجی نشست جاری و خروج را با استفاده از SQLAlchemy و PostgreSQL ارائه می‌کند.

## قابلیت‌های پیاده‌سازی‌شده
- `POST /api/auth/register`: ایجاد حساب و برگرداندن توکن نشست Bearer.
- `POST /api/auth/login`: بررسی اعتبارنامه و برگرداندن توکن نشست Bearer.
- `GET /api/auth/me`: اعتبارسنجی توکن Bearer جاری و برگرداندن کاربر.
- `POST /api/auth/logout`: باطل‌کردن نشست جاری.
- گذرواژه‌ها با Argon2 هش می‌شوند.
- توکن‌های نشست به‌صورت رمزنگارانه تصادفی هستند؛ فقط هش SHA-256 آن‌ها در پایگاه داده ذخیره می‌شود.
- نشست‌ها پس از هفت روز منقضی می‌شوند.
- فرانت‌اند توکن و کاربر جاری را در `localStorage` نگه می‌دارد و هنگام شروع برنامه، نشست را با `/api/auth/me` اعتبارسنجی می‌کند.

## استقرار
۱. مقدار `DATABASE_URL` را برابر URI مربوط به PostgreSQL Session Pooler ارائه‌دهنده پایگاه داده قرار دهید.  
۲. مقدار `CORS_ORIGINS` را دقیقاً برابر مبدأ فرانت‌اند تنظیم کنید.  
۳. متغیر مخزن GitHub Actions با نام `VITE_API_URL` را برابر مبدأ عمومی HTTPS بک‌اند و بدون اسلش انتهایی قرار دهید.  
۴. اعتبارنامه‌های پایگاه داده را محرمانه و خارج از بسته فرانت‌اند نگه دارید.

## محدودیت‌های امنیتی
- تأیید ایمیل و بازیابی گذرواژه پیاده‌سازی نشده‌اند.
- محدودسازی نرخ دیتابیس‌محور برای ثبت‌نام و ورود پیاده‌سازی شده است: ثبت‌نام ۲۰ تلاش در ساعت به‌ازای IP و ورود ۵ تلاش در ۱۵ دقیقه به‌ازای حساب+IP. محافظت‌های تکمیلی، پایش و هشداردهی همچنان نیازمند کار هستند.
- در سند مبدأ این فایل، تغییرات طرح پایگاه داده هنوز بدون migration توصیف شده‌اند؛ اما مستند معماری و استقرار جدیدتر، Alembic را پیکربندی‌شده اعلام می‌کنند. برای وضعیت جاری مهاجرت‌ها به [مستند معماری](./ARCHITECTURE.md) و [راهنمای استقرار](./deployment.md) رجوع کنید.
- فرانت‌اند توکن Bearer را در `localStorage` نگه می‌دارد. این روش برای آلفا ساده است، اما اثر آسیب‌پذیری XSS را بیشتر می‌کند. برای نسخه عملیاتی، کوکی امن HttpOnly همراه با محافظت CSRF بررسی شود.
- نشست منقضی هنگام استفاده رد می‌شود، اما job زمان‌بندی‌شده‌ای برای پاک‌سازی ردیف‌های نشست قدیمی وجود ندارد.

## طرح مهاجرت به Cookie امن\nطرح معماری در [پیشنهاد مهاجرت احراز هویت به Cookie امن](./AUTH_COOKIE_MIGRATION.md) ثبت شده است. این طرح هنوز اجرا نشده و به دامنه اختصاصی مشترک برای فرانت‌اند و API نیاز دارد. تا آن زمان، روش Bearer فعلی بدون تغییر باقی می‌ماند.\n\nاین پروژه را آلفا در نظر بگیرید، نه سامانه هویت آماده تولید. گذرواژه پایگاه داده، توکن Bearer یا اطلاعات محرمانه دیگر را در Git ثبت یا با دیگران به اشتراک نگذارید.
