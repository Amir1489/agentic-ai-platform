# قابلیت اطمینان اجرای Agent Task

## Lease و heartbeat
هر Task در زمان claim یک شناسه worker، یک lease token تصادفی، زمان claim، زمان آخرین heartbeat و زمان انقضای lease دریافت می‌کند. worker در طول درخواست مدل هر ۱۵ ثانیه lease را تمدید می‌کند؛ lease پس از ۹۰ ثانیه بدون heartbeat منقضی می‌شود. heartbeat، ثبت نتیجه و زمان‌بندی retry همگی lease token همان claim را بررسی می‌کنند تا اجرای قدیمی نتواند نتیجه اجرای جدید را بازنویسی کند.

## تلاش مجدد با Exponential Backoff
تعداد تلاش‌ها به ۳ محدود است. پس از شکست موقت provider، Task با زمان next_retry_at به صف برمی‌گردد و تا رسیدن آن زمان قابل claim نیست. تأخیر پایه ۵ ثانیه است، در هر تلاش دو برابر می‌شود، در ۶۰ ثانیه سقف دارد و ±۲۰٪ jitter تصادفی برای جلوگیری از هم‌زمانی درخواست‌ها اعمال می‌شود. زمان‌بندی در دیتابیس ذخیره می‌شود و پس از restart باقی می‌ماند.

خطاهای HTTP 429، 5xx، timeout و خطاهای اتصال موقت قابل retry هستند. خطاهای احراز هویت/درخواست (از جمله 4xx غیر از 429)، پاسخ نامعتبر provider، نبود تنظیمات provider و خطاهای غیرمنتظره داخلی retry نمی‌شوند. پیام خطای ذخیره‌شده جزئیات محرمانه provider را افشا نمی‌کند.

## بازیابی و تلاش مجدد
worker در هر چرخه Taskهای running با lease منقضی‌شده را بررسی می‌کند. اگر سقف تلاش باقی مانده باشد، Task با همان سیاست backoff زمان‌بندی می‌شود؛ در غیر این صورت failed می‌شود. رویدادهای recovered، retry_scheduled و failed در تاریخچه ثبت می‌شوند.

## مالکیت اجرا و idempotency
claim با UPDATE شرطی انجام می‌شود. هر claim یک lease token جدید می‌گیرد. heartbeat، finish و retry_or_fail فقط وقتی مجازند که Task هنوز running و متعلق به همان worker و همان lease token باشد. این fencing از ثبت نتیجه توسط اجرای قدیمی جلوگیری می‌کند، اما به‌تنهایی از تکرار درخواست خارجی provider پس از crash جلوگیری نمی‌کند؛ برای تضمین exactly-once در سرویس مقصد، پشتیبانی idempotency key از سوی آن سرویس لازم است.

## محدودیت‌ها
این پیاده‌سازی همچنان worker را داخل فرایند API اجرا می‌کند. برای مقیاس‌پذیری چندسرویسی، صف مستقل و worker جداگانه لازم است. timeout سمت provider فعلاً ۴۵ ثانیه است. اجرای مدل ممکن است پس از انقضای lease در سمت provider ادامه یابد، اما نتیجه آن با lease token قدیمی ذخیره نمی‌شود.
